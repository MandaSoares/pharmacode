# PharmaCode

App de leitura assistida de bulas de medicamento para idosos e pessoas com baixa visao.

## Como rodar

1. Instalar Node.js (v18+): https://nodejs.org
2. Instalar Expo Go no celular (Play Store / App Store)
3. Clonar o repo: `git clone https://github.com/SEU_USER/pharmacode.git`
4. Entrar na pasta: `cd pharmacode`
5. Instalar dependencias: `npm install`
6. Rodar: `npx expo start`
7. Escanear o QR code com o Expo Go no celular

## Stack

- React Native + Expo
- expo-camera (leitura de codigo de barras)
- expo-speech (Text-to-Speech)
- expo-haptics (feedback vibratorio)
- @react-navigation (navegacao entre telas)
- AsyncStorage (perfil e configuracoes locais)
